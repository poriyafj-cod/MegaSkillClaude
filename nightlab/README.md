# NIGHTLAB — نایت‌لب 🌙

بوتیک بزرگسالان با زبان طراحی «لابراتوار شب»: زردِ هشدار، مشکی، تایپوگرافی صنعتی و
پوسترِ بنیان‌گذار به سبک چاپ سیلک. فروشگاه کامل، فارسی و RTL، بدون هیچ وابستگی در زمان اجرا.

> این پروژه یک **فروشگاه نمایشی** است: پرداخت واقعی، حساب کاربری و پیامک ندارد.
> همهٔ محتوا برای بزرگسالان (۱۸+) است و هیچ تصویر یا توصیف جنسی صریحی در آن نیست.

---

## ۱. اجرا

```bash
cd nightlab
npm run dev        # http://localhost:4321
npm run verify     # لینک‌ها، تصاویر، ترتیب اسکریپت‌ها و سالم بودن کاتالوگ
npm i --no-save jsdom && npm run smoke   # ۶۹ تست جریان خرید با jsdom
```

| --- | --- | --- |

## ۳. معماری

```
assets/css/tokens.css       توکن‌ها (زرد هشدار، کریستال آبی، مونو)، ریست، تایپ
assets/css/components.css   دکمه‌ها، هدر/فوتر، نوار اطلاع، نوار خطر، کاشی جدول تناوبی، دروازهٔ ۱۸+، توست، کشو
assets/css/pages.css        هیرو پوستری، دسته‌ها، کیت‌بند، فروشگاه، PDP، سبد، درباره، تماس، راهنما

assets/js/icons.js          آیکون‌های SVG درون‌خطی
assets/js/data.js           ۱۲ محصول، ۵ دسته، بسته‌ها، کوپن‌ها + سازندهٔ «ویال آزمایشگاهی» SVG
assets/js/store.js          سبد/علاقه‌مندی/کوپن/سفارش روی localStorage
assets/js/ui.js             هدر، فوتر، دروازهٔ ۱۸+، کشوی سبد، جست‌وجو، توست، کارت محصول
assets/js/home|shop|product|cart|wishlist|contact.js
```

ترتیب ثابت اسکریپت‌ها: `icons → data → store → ui → صفحه` (بررسی خودکار در `verify.mjs`).

## ۴. هویت و ارجاع‌های بصری

- **پالت**: زرد هشدار `#f5c518`، مشکی `#08090b`، کریستال آبی `#57e0ff`، مینت `#a9ecff`.
- **ارجاع‌ها**: نوار خطر زرد/مشکی، کاشی جدول تناوبی (`Nl`)، برچسب‌های مونو، خط‌کش اندازه‌گیری،
  «۹۹٫۱٪ خالص» و پوستر چاپ‌سیلک بنیان‌گذار — همه اشاره به زیبایی‌شناسی «آزمایشگاه/والتر وایت» و
  «شریک بی‌قرار/جسی پینک‌من»، بدون هیچ اشاره به مواد.
- **تصویر بنیان‌گذار**: عکس خودت، در سه نسخه (`founder-portrait`, `founder-poster`, `founder-avatar`).
  اگر عکس کس دیگری است، قبل از انتشار عمومی **رضایت کتبی** لازم است.

## ۶. حریم خصوصی و ایمنی (در خود سایت هم نوشته شده)

- بسته‌بندی بی‌نام، فاکتور با عنوان خنثی، پیامک فقط با کد رهگیری.
- حساب کاربری ندارد؛ سبد/علاقه‌مندی/سفارش در مرورگر همان دستگاه می‌ماند.
- دروازهٔ ۱۸+ در اولین بازدید، با ذخیرهٔ انتخاب در `localStorage`.
- بازگشت فقط برای بستهٔ پلمب‌نشده (دلیل بهداشتی)، با هزینهٔ برگشت به عهدهٔ فروشگاه.

## ۷. انتشار روی Vercel

- Root Directory: `nightlab`
- Build Command: `sh build.sh`
- Output Directory: `dist`
- Install Command: `npm install --no-audit --no-fund` (هیچ وابستگی‌ای نصب نمی‌شود)
- `vercel.json`: `cleanUrls` + هدرهای کش/امنیتی

## ۸. قدم‌های بعدی

1. عکس واقعی محصولات (با نور استودیویی و پس‌زمینه تیره) به‌جای تصویرسازی SVG.
2. اتصال `store.js` به API واقعی + درگاه پرداخت با عنوان خنثی.
3. حساب کاربری اختیاری با نام مستعار و پاک‌شدن خودکار سبد.
4. داده‌ساختاریافتهٔ `Product` و مسیر `/product/<slug>`.
