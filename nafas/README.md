# نفس · NAFAS — فروشگاه اکسسوری دخترانه (تینیجری)

سایت کامل، دقیق و قابل استفاده برای برند اکسسوری **نفس**، با جهت‌گیری طراحی «تینیجری / استریت‌ویر»:
بنفش پرانرژی، تایپوگرافی درشت، کارت‌های نرم و میکرو‌انیمیشن‌های سبک.

سایت **استاتیک و بدون بیلد** است (HTML + CSS + JS خالص) تا بدون هیچ وابستگی‌ای روی هر هاست یا
Vercel/GitHub Pages بالا بیاید، اما همهٔ جریان‌های فروش (سبد خرید، علاقه‌مندی، کد تخفیف، تسویه،
تأیید سفارش، جست‌وجو، فیلتر و مرتب‌سازی) واقعی و کارا هستند و در `localStorage` ذخیره می‌شوند.

## ۲. سیستم طراحی

- **رنگ‌ها:** بنفش اصلی `#6F3FF5`، رمپ بنفش (`#241058` تا `#F7FAFF`)، کرم کاغذی `#FFFCF7`،
  آکسنت لیمویی `#DCFF7A` و صورتی `#FF8FD3`.
- **تایپوگرافی:** `Vazirmatn` برای فارسی (۳۰۰ تا ۹۰۰) + `Anton` برای تیترهای انگلیسی دکوراتیو
  (NAFAS / OWN YOUR WORLD / LOOKBOOK).
- **شکل‌ها:** شعاع‌های بزرگ (۱۶ تا ۴۴ پیکسل)، پیل‌های کامل، سایه‌های نرم بنفش‌رنگ.
- **کارت محصول:** کاشی ۴:۵ با گرادیان لیلکی؛ عکس محصول با `mix-blend-mode: multiply` داخل کاشی
  می‌نشیند تا کل کاتالوگ — با وجود عکس‌های متفاوت — یکدست دیده شود. عکس دوم (جزئیات) با هاور
  جای عکس اول را می‌گیرد.
- **حرکت:** ریویل آرام با IntersectionObserver، مارکی، شمارش معکوس، کارت‌های شناور هیرو؛
  همه با `prefers-reduced-motion` خاموش می‌شوند.
- **RTL واقعی:** همه‌جا از پراپرتی‌های منطقی (`margin-inline`, `inset-inline`) استفاده شده؛
  کشوها از سمت راست باز می‌شوند و آیکون‌ها جهت‌دار هستند.

## ۳. صفحات

| صفحه | فایل | چه‌چیزی دارد |
|---|---|---|
| خانه | `index.html` | هیرو با عکس برند + کارت‌های شناور، مارکی، ۶ دسته، ۸ پرفروش، بنر کالکشن با شمارش معکوس، لایک‌بوک، تازه‌رسیده‌ها، مزیت‌ها، نظرات، گالری `#nafasstyle`، خبرنامه |
| فروشگاه | `shop.html` | فیلتر دسته/قیمت/رنگ/موجودی، مرتب‌سازی، چیپ‌های فیلتر فعال، شمارش نتایج، «بیشتر نشان بده»، همگام‌سازی با URL (`?cat=`, `?tag=`, `?q=`, `?sort=`) |
| محصول | `product.html?p=slug` | گالری دو تصویری، انتخاب رنگ/سایز/حرف، تعداد، افزودن به سبد، علاقه‌مندی، مشخصات، آکاردئون ارسال و مرجوعی، نظرات، پیشنهادهای مرتبط، حالت «محصول پیدا نشد» |
| سبد خرید | `cart.html` | خطوط سفارش با تغییر تعداد/حذف، کد تخفیف، نوار «تا ارسال رایگان»، مرحلهٔ اطلاعات ارسال با اعتبارسنجی فارسی، روش پرداخت (آنلاین/کارت‌به‌کارت/در محل با هزینهٔ اضافه)، تأیید سفارش با کد رهگیری |
| علاقه‌مندی‌ها | `wishlist.html` | گرید ذخیره‌شده‌ها + حالت خالی |
| داستان نفس | `about.html` | روایت برند با عکس، سه ارزش، تایم‌لاین دو ساله |
| تماس | `contact.html` | کارت‌های ارتباط، فرم اعتبارسنجی‌شده، نقشه، ۵ سؤال متداول آکاردئونی |

هدر/فوتر/کشوی سبد/مُدال جست‌وجو/توست‌ها یک‌جا در `assets/js/ui.js` ساخته می‌شوند تا در همهٔ
صفحات یکسان بمانند (تک منبع حقیقت).

### قابلیت‌های تجاری پیاده‌شده
- سبد خرید پایدار در `localStorage` با کلید نسخه‌دار (`nafas.cart.v1`)
- کدهای تخفیف: `NAFAS10` (۱۰٪)، `TEEN15` (۱۵٪ بالای ۱ میلیون)، `FREE` (ارسال رایگان)
- ارسال رایگان بالای ۱٬۲۰۰٬۰۰۰ تومان + نوار پیشرفت
- علاقه‌مندی، جست‌وجوی زنده با امتیازدهی متنی، پیشنهادهای پرجست‌وجو
- ذخیرهٔ سفارش‌ها در `nafas.orders.v1` (۲۰ سفارش آخر)

## ۴. اجرا

```bash
cd nafas
npm run dev          # http://localhost:4321  (سرور استاتیک بدون وابستگی)
```

یا هر سرور استاتیک دیگر؛ نیازی به بیلد نیست. فونت‌ها از Google Fonts می‌آیند و در نبود اینترنت،
به فونت سیستم fallback می‌شوند.

## ۵. تست و بررسی

```bash
npm run verify       # همهٔ لینک‌ها/تصاویر موجودند؟ کاتالوگ سالم است؟ JS پارس می‌شود؟
npm run smoke        # ۴۲ تست جریان واقعی با jsdom (خانه، فیلتر، محصول، سبد، تسویه، تماس)
```

آخرین اجرا: `verify` ✅ ۷ صفحه / ۱۴ محصول / ۱۰ اسکریپت، و `smoke` ✅ ۴۲ از ۴۲.

**داده‌ها:** همهٔ محصولات، دسته‌ها، کدهای تخفیف، سؤالات متداول و نظرات در `assets/js/data.js`
هستند. برای افزودن محصول تازه: یک آبجکت به آرایهٔ `products` اضافه کنید و دو تصویر
`slug.jpg` و `slug-detail.jpg` را در `assets/img/products/` بگذارید — بقیهٔ سایت (گرید، فیلتر،
جست‌وجو، صفحهٔ محصول، پیشنهادها) خودکار به‌روز می‌شود.

## ۷. محدودیت‌های آگاهانه

- این یک **فروشگاه نمایشی/فرانت‌اند** است: پرداخت واقعی، ارسال ایمیل/پیامک و پنل مدیریت ندارد.
  سفارش‌ها فقط در مرورگر ذخیره می‌شوند (در مرحلهٔ تأیید سفارش هم به کاربر گفته می‌شود).
- عکس محصولات از تصاویر استودیویی آزاد/فروشگاهی وب انتخاب و یکدست‌سازی شده‌اند تا کاتالوگ
  نمایشی کامل باشد؛ برای فروش واقعی جای‌گذاری با عکس‌های رسمی برند لازم است.
- برای اتصال به بک‌اند واقعی، فقط `store.js` را با لایهٔ API عوض کنید؛ بقیهٔ رابط کاربری دست‌نخورده
  می‌ماند.

## ۸. قدم‌های بعدی پیشنهادی

1. اتصال `store.js` به یک API (محصولات، سفارش، موجودی) و احراز هویت.
2. درگاه پرداخت (زرین‌پال/آیدی‌پی) و پیامک تأیید سفارش.
3. آپلود عکس‌های واقعی محصول روی همان نام‌گذاری `slug.jpg` (بدون تغییر کد).
4. اتصال فید اینستاگرام به بخش `#nafasstyle` و افزودن ریویوهای واقعی.
5. سئوی پیشرفته: `sitemap.xml`, داده‌ساختاریافتهٔ `Product`، و تبدیل صفحهٔ محصول به مسیر
   `/product/<slug>` با ریدایرکت.
