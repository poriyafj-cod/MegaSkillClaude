### تست‌های اجراشده (۲۰۲۶-۱۰-۳۰)
- `npm run verify` → ✅ ۷ صفحه، ۱۴ محصول، ۱۰ اسکریپت، بدون لینک/فایل گم‌شده
- `npm run smoke` → ✅ ۴۲/۴۲ (jsdom): مانت‌شدن کروم، رندر کاتالوگ، فیلتر و مرتب‌سازی، صفحهٔ
  محصول، افزودن به سبد، کد تخفیف، اعتبارسنجی فرم، ثبت سفارش و پاک‌شدن سبد، علاقه‌مندی، FAQ و فرم تماس
