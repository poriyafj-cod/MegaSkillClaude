# گیت‌های انتشار یک سایت فروشگاهی

هر سایت جدید باید **همهٔ** گیت‌های زیر را بگذراند. عدد و مدرک، نه حس. گیت شکست‌خورده = انتشار نمی‌شود.

## گیت ۰ — داده و دامنه
- [ ] دامنه/زیردامنه نهایی مشخص و در `storefronts/sites.json` ثبت شده.
- [ ] تصاویر و متن‌ها مالکیت‌شان روشن است (عکس واقعی برند یا مجوز آزاد)؛ هیچ عکس استاک بدون مجوز.
- [ ] هیچ کلید/توکن/رمز در HTML، JS یا Git نیست؛ اگر بک‌اند لازم است، متغیر محیطی در Vercel.
- [ ] ادعاهای عددی (تعداد مشتری، سال تجربه، ضمانت) قابل اثبات یا صریحاً «نمونه» علامت خورده.

## گیت ۱ — ساختار
- [ ] `index / shop / product / about / contact` + ۴ صفحهٔ سیاست واقعی.
- [ ] هیچ `href="#"` برای اقدام خرید؛ هیچ لینک مرده (اسکریپت `npm run check` بازار‌یابی می‌کند).
- [ ] `lang="fa" dir="rtl"`، ترتیب تب منطقی، skip-link، یک `h1` در هر صفحه.
- [ ] `favicon` + `og:image` + `<title>` یکتا و `description` برای هر صفحه.

## گیت ۲ — تجارت
- [ ] افزودن/کاهش/حذف در سبد درست کار می‌کند و پس از رفرش می‌ماند.
- [ ] جمع سبد، تخفیف پله‌ای و آستانهٔ ارسال رایگان دقیقاً با متن صفحه یکی است.
- [ ] محصول ناموجود قابل افزودن نیست.
- [ ] اگر پرداخت واقعی نیست، هیچ دکمه‌ای «پرداخت» را شبیه‌سازی نمی‌کند؛ مسیر واقعی (تلفن/دایرکت/فرم) صریح است.

## گیت ۳ — دسترس‌پذیری و RTL
- [ ] کنتراست ≥ ۴٫۵:۱ (ابزار یا اندازه‌گیری دستی مستند).
- [ ] همهٔ تعامل‌ها با کیبورد؛ `Escape` همهٔ overlayها را می‌بندد؛ فوکوس تله در drawer.
- [ ] `prefers-reduced-motion` واقعاً خاموش می‌کند.
- [ ] عرض ۳۲۰/۳۷۵/۷۶۸/۱۰۲۴/۱۴۴۰ بدون overflow افقی.
- [ ] همهٔ تصاویر `alt` معنادار؛ تصاویر تزئینی `alt=""`.

## گیت ۴ — کارایی
- [ ] Lighthouse موبایل: Performance ≥ ۹۰، Accessibility ≥ ۹۵، Best-practices ≥ ۹۵، SEO ≥ ۹۵ (یا انحراف مستند و توضیح).
- [ ] LCP ≤ ۲٫۵s، CLS ≤ ۰٫۰۵، TBT < ۲۰۰ms.
- [ ] همهٔ تصاویر WebP/AVIF با `srcset`؛ هیرو ≤ ۲۲۰KB.
- [ ] فونت‌ها self-host شده با `font-display:swap`.

## گیت ۵ — سئو
- [ ] JSON-LD معتبر (Product/Offer در صفحهٔ محصول، Organization، FAQPage) و بدون خطای Rich Results.
- [ ] `sitemap.xml` + `robots.txt`؛ canonical درست برای `?cat`/`?tag`.
- [ ] پیش‌نمایش شبکهٔ اجتماعی درست (og:title/description/image).

## گیت ۶ — انتشار و پایش
- [ ] دیپلوی Vercel با Root Directory درست؛ لینک زنده در `sites.json` و `PROGRESS.md`.
- [ ] یک بازدید واقعی روی موبایل ثبت شده (اسکرین‌شات یا توضیح)، نه فقط build سبز.
- [ ] `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options` در `vercel.json`.
- [ ] اگر فرم/سبد داده جمع می‌کند، سیاست حریم خصوصی صادق است و داده به سرویس سوم بی‌اعلام نمی‌رود.
