# صفحه‌ها: درباره، تماس، محتوا و خطا

## درباره (`about.html`)
- ساختار: یک جملهٔ مأموریت → عکس واقعی تیم/کارگاه → سه اصل کاری (عدد/شرط) → آدرس/هویت کسب‌وکار → دعوت به محصول.
- «داستان برند» حداکثر ۳۰۰ کلمه؛ بقیه به صفحهٔ محتوا برود.
- هیچ عکس استاک بی‌ربط تیم؛ اگر عکس نداری، تصویر محصول/کارگاه بگذار و صادق باش.
- `Organization` schema با `name`, `url`, `logo`, `sameAs` (اینستاگرام/تلگرام واقعی).

## تماس (`contact.html`)
- سه کانال واقعی: تلفن/واتساپ/ایمیل + ساعات پاسخ‌دهی.
- فرم: نام، تماس، موضوع (`select`)، پیام؛ اعتبارسنجی سمت کلاینت + پیام خطای فارسی دقیق.
- اگر بک‌اند نداری، فرم را به `mailto:` یا سرویس فرم رایگان وصل کن و صریح بنویس؛ فرم دکوراتیو ممنوع.
- آدرس/نقشه فقط اگر واقعی است؛ `نشانی` متنی برای سئوی محلی کافی است.
- FAQ با `<details>` + `FAQPage`؛ پیگیری سفارش با توضیح مسیر واقعی.

## صفحات محتوا (سیاست‌ها)
`shipping.html` · `returns.html` · `privacy.html` · `terms.html` — هر کدام:
- تاریخ آخرین بازبینی، شرایط عددی (مهلت، هزینه)، و مسیر تماس.
- هیچ لینک `href="#"`؛ فوتر فقط به این چهار صفحه + دسته‌ها + تماس.

## صفحهٔ ۴۰۴
- پیام کوتاه + جست‌وجو + ۴ محصول پرفروش واقعی + لینک خانه. بدون طنز طولانی.

## وضعیت‌های خطا و خالی
| حالت | رفتار |
|---|---|
| تصویر نیامد | `onerror` → پس‌زمینهٔ `--surface-2` + آیکن، بدون آیکن شکسته |
| شبکه قطع | پیام «اتصال ندارد» + دکمهٔ تلاش مجدد؛ سبد از localStorage خوانده شود |
| نتیجهٔ خالی | توضیح دلیل + پیشنهاد جایگزین واقعی |
| محصول ناموجود | غیرفعال با «ناموجود»، بدون پنهان‌کردن قیمت قبلی |
| پرداخت ناموفق | کد خطا + راه تماس؛ بدون وعدهٔ «فردا درست می‌شود» |
