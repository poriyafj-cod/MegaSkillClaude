# صفحه: محصول (Product)

**هدف:** پاسخ به پنج پرسش خریدار، بدون پنهان‌کاری:
چه هست؟ · چقدر است؟ · چه زمانی می‌رسد؟ · اگر نپسندیدم چه؟ · چرا به شما اعتماد کنم؟

## چیدمان دسکتاپ
- ستون راست (RTL): گالری چسبان (`position:sticky`, `top:88px`).
- ستون چپ: مسیر راهنما → عنوان → امتیاز/تعداد نظر → قیمت → انتخاب نوع/رنگ/اندازه →
  نوار موجودی/ارسال → CTA اصلی → ۳ آیتم اعتماد → مشخصات کوتاه → `<details>` بیشتر.

## گالری
- تصویر اصلی + ۴–۶ بندانگشتی؛ روی موبایل swipe با `scroll-snap`.
- زوم: کلید/دابل‌تپ روی تصویر، در همان قاب (بدون لایت‌باکس پرصدا).
- **۳D اختیاری:** دکمهٔ «۳۶۰°» فقط اگر رندر واقعی داری؛ سکون همیشه تصویر استاتیک باشد.

## انتخابگر گونه
- رنگ: دایرهٔ نمونه + نام؛ انتخاب‌شده با حاشیهٔ `--ring` و `aria-checked`.
- اندازه/طعم: چیپ‌ها؛ ناموجود = خط‌خورده + `disabled` + `title="ناموجود"`.
- تغییر گونه: قیمت، تصویر و موجودی باید هم‌زمان عوض شوند؛ هیچ‌گاه قیمت متناقض با سبد.

## قیمت و اقدام
- قیمت بزرگ، تخفیف با درصد، ارسال بالای سبد مشخص.
- CTA اصلی: «افزودن به سبد» تمام‌عرض؛ CTA ثانویه: «خرید سریع» فقط اگر پرداخت واقعی وصل است.
- بعد از افزودن: بستهٔ محصول یک انیمیشن کوتاه به آیکن سبد بپرد (≤ ۴۵۰ms) + `aria-live` اعلام.
- روی موبایل نوار اقدام پایین صفحه (`position:sticky; bottom:0`) با قیمت + دکمه.

## محتوای اجباری
1. مشخصات فنی (جدول دو ستونه).
2. «چه کسی برایش مناسب است / چه کسی نه» — صادقانه.
3. نگهداری و استفاده.
4. ارسال و مرجوعی.
5. ۳–۵ پرسش متداول با `FAQPage` schema.

## سئو
- `Product` + `Offer` (price, currency IRT/IRR, availability) + `AggregateRating` **فقط با نظرات واقعی**.
- عنوان الگو: «نام محصول — دسته | برند»؛ تصویر `og:image` ۱۲۰۰×۱۵۰۰.
- محصولات مرتبط: ۴ مورد هم‌دسته، با لینک واقعی (نه بلوک مرده).
