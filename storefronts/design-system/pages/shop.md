# صفحه: فهرست محصولات (Shop)

**هدف:** رسیدن به یک محصول در ≤ ۳ تصمیم (دسته → فیلتر → کارت). بدون صفحه‌بندی گم‌کننده.

## ساختار
1. هدر جمع‌وجور: عنوان دسته + تعداد واقعی + توضیح یک‌خطی (سئو).
2. نوار کنترل: مرتب‌سازی (پرفروش، جدید، ارزان، گران)، فیلتر دسته/برچسب، «تخفیف‌دارها».
3. شبکهٔ محصول. ۲۴ کارت اول؛ بعد «بیشتر» (lazy) — نه صفحهٔ ۲ خالی.
4. بلوک سئو/اعتماد در پایان: راهنمای انتخاب + ۳ پرسش متداول.

## فیلتر و URL
- دسته و برچسب از query خوانده شوند: `?cat=necklace`، `?tag=sale`، `?sort=price-asc`.
- هر تغییر فیلتر باید URL را با `history.replaceState` به‌روز کند (اشتراک‌پذیر و back-friendly).
- حالت خالی: پیام + ۳ پیشنهاد واقعی + دکمهٔ پاک‌کردن فیلتر. «محصولی نیست» بی‌راه‌حل ممنوع.

## کارت محصول
- تصویر ۴:۵، `alt` = «نام محصول + رنگ/جنس».
- روی hover (فقط دستگاه با اشاره‌گر دقیق): تصویر دوم + «افزودن سریع».
- برچسب‌ها حداکثر ۲: `جدید`، `٪ تخفیف`، `موجودی کم`. برچسب `پرفروش` فقط اگر دادهٔ فروش داری.
- قیمت: عدد فارسی + `تومان`؛ اگر تخفیف دارد قیمت قبلی خط‌خورده و درصد محاسبه‌شده.
- محصول ناموجود: کارت غیرفعال با برچسب «ناموجود» و دکمهٔ «خبرم کن» (اگر واقعاً کار می‌کند).

## کارایی
- تصاویر `width/height` ثابت (بدون CLS)، `srcset` ۳ اندازه، `loading="lazy"` جز ۴ کارت اول.
- فیلتر سمت کلاینت فقط تا ~۲۰۰ محصول؛ بیشتر از آن ایندکس JSON و جست‌وجوی محلی.

## دسترس‌پذیری
- ناحیهٔ نتایج `aria-live="polite"` با «۱۲ محصول نمایش داده شد».
- کنترل مرتب‌سازی `<select>` بومی یا رادیوهای واقعی، نه div کلیک‌پذیر.
- شبکه `<ul>`؛ هر کارت `<li>` با عنوان `h3` داخل لینک.
