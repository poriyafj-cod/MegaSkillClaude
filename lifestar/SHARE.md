## نکته‌ها
- سبد خرید، علاقه‌مندی، کد تخفیف و سفارش در **حافظهٔ مرورگر** همان دستگاه ذخیره می‌شوند؛ بین گوشی و لپ‌تاپ همگام نمی‌شوند (فروشگاه نمایشی است).
- کدهای تخفیف قابل تست: `STAR10` · `NIGHTOWL15` · `FREESHIP`.
- دامنه‌های `vercel.app` موقتی‌اند (دیپلوی‌های production بعد از ۳۰ روز منقضی می‌شوند). برای ماندگاری، دامنهٔ اختصاصی وصل شود:
  - `A` رکورد برای دامنهٔ اصلی → `76.76.21.21`
  - `CNAME` برای `www` → `cname.vercel-dns.com`
- اجرای محلی: `cd lifestar && npm run dev` → `http://localhost:4321`
