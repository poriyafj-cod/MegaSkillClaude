# LIFE STAR — فروشگاه نوشیدنی انرژی‌زا ⚡

سایت فروش نوشیدنی انرژی‌زا با حال‌وهوای باشگاه شبانه: تم تیره، قرمز انرژی و سبز نئونی،
عکس‌های ورزشی واقعی و ۱۲ طعم نوشیدنی که هر کدام قوطی اختصاصی خودشان را دارند.

> **بدون بیلد، بدون وابستگی.** کل سایت HTML/CSS/JS خالص است و با یک فایل استاتیک اجرا می‌شود.

---

## ۱. اجرا

```bash
cd lifestar
npm run dev        # http://localhost:4321  (سرور استاتیک بی‌وابستگی)
npm run verify     # بررسی لینک‌ها، تصاویر، ترتیب اسکریپت‌ها و سالم بودن کاتالوگ
npm i --no-save jsdom && node scripts/smoke.mjs   # ۳۴ تست جریان خرید با jsdom
```

## ۲. صفحه‌ها

| صفحه | مسیر | توضیح |
| --- | --- | --- |
| خانه | `index.html` | هیرو، تیکر، دسته‌ها، پرفروش‌ها، پک‌بند، مقایسهٔ کافئین، لایک‌بوک ورزشی، نظرات، خبرنامه |
| فروشگاه | `shop.html` | فیلتر دسته/قیمت/زیرو/تخفیف/موجودی + مرتب‌سازی ۵ حالته + همگام با URL |
| محصول | `product.html?p=<slug>` | گالری (قوطی + عکس واقعی)، انتخاب پک ۱/۶/۱۲/۲۴، تعداد، ارزش غذایی، نظرات، مشابه‌ها |
| سبد و تسویه | `cart.html` | سه مرحله: سبد → اطلاعات ارسال → پرداخت، کد تخفیف، نوار ارسال رایگان، کد رهگیری سفارش |
| علاقه‌مندی‌ها | `wishlist.html` | ذخیره در مرورگر + افزودن همه به سبد |
| داستان برند | `about.html` | روایت برند + تایم‌لاین + آمار |
| تماس | `contact.html` | فرم اعتبارسنجی‌شده + ۵ پرسش متداول |
| ۴۰۴ | `404.html` | صفحهٔ خطای برندشده |

## ۳. معماری فرانت

```
assets/css/tokens.css       توکن‌های رنگ/تایپ/شعاع + ریست
assets/css/components.css   دکمه‌ها، هدر/فوتر، کارت محصول، کشوی سبد، فرم، توست
assets/css/pages.css        هیرو، فروشگاه، صفحهٔ محصول، سبد، درباره، تماس

assets/js/icons.js          ست آیکون SVG درون‌خطی (بدون درخواست شبکه)
assets/js/data.js           ۱۲ محصول، ۴ دسته، پک‌ها، کوپن‌ها + سازندهٔ قوطی SVG
assets/js/store.js          سبد/علاقه‌مندی/کوپن/سفارش روی localStorage
assets/js/ui.js             هدر، فوتر، کشوی سبد، جست‌وجو، توست، کارت محصول
assets/js/home|shop|product|cart|wishlist|contact.js
```

**ترتیب ثابت اسکریپت‌ها:** `icons → data → store → ui → صفحه`.
`verify.mjs` این ترتیب را برای هر ۸ صفحه بررسی می‌کند.

## ۴. نکته‌های تجربهٔ کاربری

- **قوطی‌های SVG** برای هر طعم، با رنگ اختصاصی و برچسب خودش؛ هیچ عکسی برای محصول لازم نیست و در
  هر اندازه‌ای شارپ است.
- **پک‌بند**: ۱ / ۶ / ۱۲ / ۲۴ عددی با تخفیف ۰ / ۸ / ۱۵ / ۲۲ درصد و قیمت واحد محاسبه‌شده.
- **قیمت‌گذاری**: ارسال ۴۵٬۰۰۰ تومان، ارسال رایگان از ۱٬۲۰۰٬۰۰۰، پرداخت در محل +۳۰٬۰۰۰.
- **کوپن‌ها**: `STAR10` (۱۰٪)، `NIGHTOWL15` (۱۵٪ بالای ۱٬۵۰۰٬۰۰۰)، `FREESHIP` (ارسال رایگان).
- **دسترس‌پذیری**: اسکیپ‌لینک، `aria-*` روی کشوها/آکاردئون‌ها، فوکوس‌رینگ نئونی، احترام به
  `prefers-reduced-motion`، متن جایگزین تصاویر.
- **RTL کامل** با پراپرتی‌های منطقی و اعداد فارسی.

## ۵. تصاویر

| مورد | منبع |
| --- | --- |
| قوطی LIFE STAR سورچری | عکس برند خود شما (`assets/img/brand/`) |
| عکس‌های ورزشی (بوکس، باشگاه، دمبل) | Pexels — لایسنس آزاد و بدون واترمارک |
| قوطی‌های سایر طعم‌ها | تصویرسازی SVG اختصاصی همین پروژه |

برای فروش واقعی، عکس محصولات جایگزین عکس استودیویی هر طعم شود (نام‌گذاری `slug.jpg`).

## ۶. انتشار روی Vercel

```bash
sh build.sh        # ساخت dist/ (صفحات + assets + robots + sitemap)
```

- Root Directory: `lifestar`
- Build Command: `sh build.sh`
- Output Directory: `dist`
- Install Command: خالی (بدون وابستگی)
- `vercel.json`: `cleanUrls` (آدرس‌های بدون `.html`) + هدرهای کش/امنیتی

## ۷. محدودیت‌های آگاهانه

- فروشگاه **نمایشی/فرانت‌اند** است: پرداخت واقعی، پیامک و پنل مدیریت ندارد؛ سفارش‌ها فقط در
  مرورگر ذخیره می‌شوند (در مرحلهٔ تأیید هم به کاربر گفته می‌شود).
- محتوای محصولات، برند و آمار نمونه است و باید با اطلاعات واقعی جایگزین شود.
- نوشیدنی انرژی‌زا برای افراد زیر ۱۸ سال، بارداری و افراد با فشار خون توصیه نمی‌شود؛ این
  هشدار در صفحهٔ محصول و فوتر آمده است.

## ۸. قدم‌های بعدی

1. اتصال `store.js` به API واقعی (موجودی، سفارش، پرداخت زرین‌پال).
2. عکس استودیویی ۱۲ طعم + ویدیوی کوتاه کمپین در هیرو.
3. باشگاه مشتریان و اشتراک ماهانه («هر ۳۰ روز یک پک ۲۴ عددی»).
4. داده‌ساختاریافتهٔ `Product` و مسیر `/product/<slug>`.
