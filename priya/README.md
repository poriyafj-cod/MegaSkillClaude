# پریا 🌸 — خوشگل‌ترین دختر جهان

سایت تک‌صفحه‌ای، صورتی و رویایی، ساخته‌شده با ❤️ برای **پریا** — خوشگل‌ترین دختر جهان.

سایت **استاتیک و بدون بیلد** است (HTML + CSS + JS خالص)؛ بدون هیچ وابستگی‌ای روی هر هاست، Vercel یا GitHub Pages بالا می‌آید.

## بخش‌ها

- **هیرو:** اسم بزرگ پریا با گرادیان صورتی، عکس در قاب طاقی، کارت‌های شناور و آمار «۱۰۰٪ خوشگل»
- **درباره پریا:** ۴ کارت کیفیت (مهربون، درخشان، خاص، قوی)
- **گالری:** عکس اصلی + کارت‌های هنری گرادیانی با کپشن‌های عاشقانه
- **حرف قشنگ:** مولد ۲۰ حرف قشنگ فارسی با دکمه‌ی «یه حرف قشنگ دیگه بگو»
- **نامه:** پاکت نامه‌ی تعاملی که با کلیک باز می‌شود و نامه‌ی عاشقانه را نشان می‌دهد
- **چرا تو؟:** ۱۲ دلیل که پریا بهترینه
- **فوتر:** امضای «Priya» با فونت دست‌نویس

## تعامل‌ها

- گلبرگ‌های 🌸 در حال سقوط روی کل صفحه (Canvas)
- قلب ترکیدن هنگام کلیک روی هرجا / عکس‌ها / دکمه‌ها
- رد قلب دنبال‌کننده‌ی موس
- انیمیشن ریویل هنگام اسکرول (IntersectionObserver)
- شمارنده‌های فارسی با اعداد فارسی

## اجرا

```bash
cd priya
python3 -m http.server 8000
# باز کن: http://localhost:8000
```

یا با Node:

```bash
npx serve .
```

## استقرار روی Vercel

Root Directory را روی `priya` بگذارید؛ Framework Preset: Other. هیچ تنظیم خاصی لازم نیست.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | ساختار صفحه (RTL، فارسی) |
| `style.css` | سیستم طراحی صورتی/لاوندر |
| `script.js` | گلبرگ‌ها، حرف قشنگ، پاکت، قلب‌ها |
| `assets/priya.jpg` | عکس پریا (بهینه‌سازی‌شده، ۱۰۸۰px) |
